# The Science of Effective Learning

**원본:** raw/articles/example-effective-learning.md

## 요약

학습 효과는 세 가지 핵심 요소에 좌우된다: 분산 반복(Spaced Repetition), 적극적 재호출(Active Recall), 그리고 인터리빙(Interleaving). 이들은 전통적인 교육의 집중식 학습(Massed Practice) 방식과 모순된다.

## 핵심 발견

- **분산 반복**: 시간 간격을 두고 반복 검토하면 집중식 학습 대비 50% 높은 보유율
- **적극적 재호출**: 자체 테스트가 수동적 재읽기보다 2-3배 효과적
- **인터리빙**: 다양한 주제 혼합은 새로운 문제로의 전이 학습을 개선하지만 학습 중에는 어려워 보임

## 학습 사이클

1. **Encode** — 초기 노출
2. **Retrieve** — 자체 테스트
3. **Consolidate** — 수면 + 시간 간격
4. **Transfer** — 새로운 맥락에 적용

## 실제 적용

- 공부 세션: 25-50분 + 휴식
- Anki 같은 분산 스케줄링 플래시카드 사용
- 다른 사람에게 설명하기로 이해도 강화
- 연습 중 문제 유형 변화
