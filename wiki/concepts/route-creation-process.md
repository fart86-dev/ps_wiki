# 경로 생성 프로세스 (시스템)

관리자 시스템(경로제작 화면)에서 경로를 만드는 6단계 절차.

## 6단계 프로세스

### 1단계: 탑승자 데이터 불러오기
- 탑승자 탭 → 알림받기 검색
- 필터 조건:
  - **신청 기간** — 데이터 조회 기간
  - **시간 선택** — 해당 출근 시간대 (7:10 ~ 20:00)
  - **탑승지/하차지 지역** — 범위 제한
- 필터링된 후보 중 경로에 사용할 탑승자를 오른쪽 리스트로 이동

### 2단계: Point 찍기
- 지도에서 정류장 후보 위치를 점(Point)으로 표시
- 용도: 검색 및 위치 확인
- 정류장 위치는 아직 후보 상태

### 3단계: LineString 생성
- Tmap 길찾기로 실제 도로선 생성
- 기능: 지도에서 경로의 도로선을 확인 (자연스러운지 검토)
- 결과: 정확한 경로 도로선

### 4단계: 정류장 확정
- 도로선 확인 후 정류장 위치 최종 확정
- Point에서 LineString 기반으로 이동

### 5단계: 경로 생성 (자동)
- 탑승자 데이터 + 도로선을 서버에 전송
- 서버 자동 처리:
  - 정류장 생성
  - 탑승자 할당
- 결과: 초안 경로

### 6단계: 경로 제작 (수동 저장)
- 자동 생성 결과 검토
- 메타데이터 입력 (아래 참조)
- 최종 저장

## 경로 제작 폼 항목

경로 저장 시 입력해야 할 10개 항목:

| 항목 | 의미 | 주의사항 |
|------|------|---------|
| **탑승지 / 상세** | 출발 정류장 주소 | 필수 입력 |
| **하차지 / 상세** | 도착 정류장 주소 | 필수 입력 |
| **시간** | 운행 시간 | 출근/퇴근 방향에 맞게 설정 |
| **결제** | 고객 요금 청구 여부 | B2B(기업)=X, B2C(일반)=O |
| **활성** | 현재 운영 여부 | 비활성이면 앱에 미표시 |
| **출퇴근** | 출근/퇴근 방향 | 같은 노선도 별도 경로로 생성 |
| **사업** | B2C vs B2B 구분 | 정산 방식이 달라지므로 필수 |
| **좌석** | 고객의 좌석 선택 여부 | O=고객 선택, X=자동 배정 |
| **검색** | 앱에서 검색 노출 | X이면 링크로만 접근 가능 |
| **경로추천 등록** | 경로 추천 시스템 포함 | 추후 별도 등록 |

## 지도 탑승자 데이터 표시

### 마커 색상 구분
- 🟢 **초록색** — 탑승지 (집, 출발 위치)
- 🔴 **빨간색** — 하차지 (회사, 도착 위치)

### 데이터 목록 상태
- **왼쪽 목록** — 후보 탑승자
- **오른쪽 목록** — 경로 생성에 사용할 확정 데이터

## 핵심 주의사항

1. **메타데이터 오류의 영향**
   - 고객이 경로를 찾지 못함 (검색 설정 오류)
   - 결제가 되지 않음 (결제 설정 오류)
   - 운행이 되지 않음 (활성/사업 설정 오류)

2. **출퇴근 방향**
   - 같은 노선도 출근/퇴근을 별도 경로로 생성
   - 시간 설정 중요

3. **사업 구분의 중요성**
   - 정산 방식이 달라짐
   - 반드시 정확히 설정
