# 클러스터 (Clustering)

경로 생성의 기초가 되는 공간적 그룹화 개념.

## 작동 원리

시스템이 지도를 **보이지 않는 육각형 구역**으로 나누고, 같은 구역 또는 인접한 구역에 사는 신청자들을 자동으로 묶음.

## 핵심 도구: Zoom(Resolution)

지도에서 **zoom 숫자**로 육각형 구역의 크기를 조절:

| Zoom 숫자 | 육각형 크기 | 결과 |
|----------|-----------|------|
| **크다** | 좁아짐 | 더 가까운 사람들끼리만 묶임 |
| **작다** | 넓어짐 | 더 많은 사람이 한 그룹으로 묶임 |

## 중요성

> 클러스터를 이해하지 못하면 지도에서 어떤 그룹이 경로가 될 수 있는지 판단하기 어렵습니다.

**의사결정 프로세스:**
1. 알림받기 신청 데이터 확인
2. **클러스터 토글 켜기** (필수!)
3. Zoom 조절하며 경로 가능한 그룹 찾기
4. 경로 생성 가능한 그룹 판단
5. 경로 생성 진행

## 클러스터 vs 개별 신청자

### 클러스터 토글 ON
- 자동 그룹화
- 경로가 될 만한 그룹을 시각적으로 파악 용이
- **경로 생성 의사결정의 기초**

### 클러스터 토글 OFF
- 개별 신청자만 표시
- 디테일한 위치 확인 가능
- 경로 확정 후 세부 조정 시 유용

## 운영팀의 의사결정 프로세스

1. 알림받기 신청 데이터 수집
2. **클러스터 토글 ON** (필수!)
3. **Zoom 조절** 하며 그룹 확인
4. 경로 가능한 그룹 판단
5. 경로 생성 진행 → [경로 생성 프로세스](../concepts/route-creation-process.md)
