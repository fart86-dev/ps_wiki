# 마케팅 (수요 기반 경로 모집)

알림받기 신청자들을 목표 인원으로 모집하는 활동.

## 발생 시점

**수요 기반 경로 생성 후** — 배차로 진행하기 전

요청 기반(기업/단체) 경로는 마케팅 단계 없음 (인원 이미 확보)

## 프로세스

```
경로 생성
    ↓
마케팅 시작 (전화, 문자)
    ↓
알림받기 신청자 모집
    ↓
목표 인원 달성
    ↓
배차 진행
```

## 마케팅 수단

- **전화**: 직접 설득, 높은 전환율
- **문자**: 대량 연락, 낮은 비용
- 조합: 중요 대상은 전화, 나머지는 문자

## 목표 인원 결정

- "목표 인원"의 기준 불명확 (domain detail에서 다뤄야 함)
- 경로 채산성, 기사 효율성, 고객 만족도 종합 판단

## 의존성

### 입력 데이터
- 알림받기 신청자 목록
- 신청자의 집 위치, 회사, 시간
- 신청자 연락처

### 성공 요소
- 마케팅 메시지의 설득력
- 시간 대응성
- 탑승 편의성

## 위험 요소

- **목표 미달성** → 경로 생성 실패 또는 폐지
- **모집 지연** → 배차 일정 영향
- **취소/이탈** → 경로 인원 감소로 폐지 위험
