# Interleaving (인터리빙)

학습 중 다양한 주제나 문제 유형을 혼합하는 기법. 같은 주제를 연속으로 푸는 것(blocked practice) 대신 섞어가며 풀기.

## 효과

- **전이 학습 개선** — 새로운 문제 유형에 더 잘 적용
- **학습 곡선의 착각(illusion of competence) 극복**
- 장기 기억과 패턴 인식 강화

## 단점

- 학습 중에는 매우 어렵고 느려 보임
- 초기 성과가 낮아 보여 좌절감 유발 가능
- 따라서 많은 학생과 교사가 사용하지 않는 경향

## 메커니즘

다양한 문제를 섞으면 학생이 "어떤 전략을 사용할지" 결정하는 과정을 매번 거친다.  
반면 blocked practice (같은 유형만 반복)는 자동 실행만 하므로 새로운 상황에 적용 불가.

## 실제 예시

- **수학**: 덧셈만 10개 → 덧셈, 뺄셈, 곱셈 섞여서 15개
- **언어**: 같은 문법만 → 다양한 문법과 단어 혼합
- **운동**: 같은 동작 반복 → 다양한 동작 조합
