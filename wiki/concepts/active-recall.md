# Active Recall (적극적 재호출)

자료를 수동적으로 다시 읽지 않고, 스스로 상기하도록 강요하는 학습 전략. 검색 연습(Retrieval Practice)이라고도 함.

## 효과

- 수동적 재읽기보다 **2-3배 효과적**
- 장기 보유율 극적으로 향상
- 깊은 이해와 전이 학습 촉진

## 메커니즘

기억을 "꺼내려" 할 때, 뇌는 더 강한 신경 경로를 형성한다.  
단순 노출(passive exposure)은 약한 인코딩만 생성.

## 구현 방법

1. **자체 테스트** — 설명하고 회상해보기
2. **플래시카드** — 자신에게 질문하기
3. **요약 쓰기** — 자신의 말로 설명
4. **다른 사람에게 가르치기** — 최강의 형태
